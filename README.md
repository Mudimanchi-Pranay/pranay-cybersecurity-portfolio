This package keeps the existing portfolio content and applies the five requested changes:

1. Removed the `01 / 02 / 03...` numbers from the top navigation.
2. Replaced the right-side profile card with a central, background-removed Pranay portrait surrounded by animated cybersecurity data cards, orbit rings, scan effects, glow, and pointer-based 3D motion.

## Vercel

The project is a Vite + React application. Extract the folder, run `npm install`, then `npm run dev` locally. For Vercel, import the project folder/repository; Vercel should detect Vite automatically. Build command: `npm run build`. Output directory: `dist`.
